# نتائجي | Nataiji

## الإصدار الحالي
**Nataiji v1.0.0 RC1** (`1.0.0-rc.1`) — نسخة مرشحة للإطلاق، مجمدة الميزات قبل الإصدار النهائي.

مشروع مستقل لإدارة النتائج الدراسية.

## النطاق
- إنشاء الأقسام وإدارة التلاميذ.
- إدخال درجات المواد وحساب المجموع والمعدل والترتيب.
- لائحة نتائج القسم.
- كشف درجات فردي مطابق للنمط المدرسي الموريتاني.
- مشاركة القسم بين المعلمين عبر رمز دعوة.
- صلاحيات مرنة يمنحها صاحب الدعوة للمعلم المدعو.
- طباعة وتصدير النتائج.

## التشغيل
`npm install && npm start`
