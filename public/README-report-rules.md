# Nataiji official report rules

- Arabic remains the primary fixed language of official reports and printed student/class lists; switching the application UI to French must not flip document direction or translate personal names.
- Each subject is displayed with its Arabic official name and its full French name (not an abbreviation). The French subject name is editable in subject settings.
- First trimester report contains first-trimester results only.
- Second trimester report contains second-trimester results only.
- Third trimester is the only report allowed to include the three trimester summaries and annual/final result section.
- Teacher and director signature zones must remain close to the result table and include subordinate assistant labels and usable signing space.
- Preserve A4 print geometry and existing two-students-per-page batch layout.
